# 📊 EdTech Analysis Dashboard | Power BI

## 📌 Project Overview
The **EdTech Analysis Dashboard** is a data visualization project developed using Microsoft Power BI. It helps analyze educational data and present insights through interactive charts, graphs, and reports.

The dashboard aims to make educational data easier to understand and supports data-driven decision-making.

## 🎯 Objectives
- Analyze educational data using Power BI.
- Create interactive dashboards for data visualization.
- Identify important trends and patterns in the data.
- Present data insights in a simple and understandable format.
- Improve data analysis and business intelligence skills.

## 🛠️ Technologies Used
- **Microsoft Power BI** – Dashboard development and visualization.
- **Data Analysis** – Exploring and interpreting data.
- **Data Visualization** – Presenting insights through charts and graphs.
- **Power Query** – Data cleaning and transformation, if used in the project.
